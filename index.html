About

I'm a senior backend engineer in São Paulo with 10+ years shipping distributed systems for financial institutions — from banks to the Brazilian stock market (B3), where products handle 10M+ operations a day. High-availability platforms built on Go, Java/Spring Boot, Kafka, NATS and Kubernetes, processing tens of millions of transactions daily.

At Itaú Unibanco I work as a cross-functional engineer across squads, and I've modernized large legacy services by porting them to Go on cloud-native, Kubernetes-based platforms.

Security and regulatory compliance have run through most of my career: PCI-DSS, Bacen (Brazilian Central Bank) regulations and PIX, cryptography (RSA/AES), HSM/KMS key management and TLS/mTLS — from EMV card migrations to hardening cloud-native payment platforms.

Outside work I live in the Go ecosystem (300+ public repos), build at the intersection of Go and AI — llama.cpp bindings, Claude Code agent tooling, MCP servers — and I'm learning Rust by rewriting things in it.

I build and maintain inovacc (InovaCloud Consultoria), an open-source ecosystem of Go tooling. Most of my time goes to unravel — a security-research CLI/MCP server that dissects desktop & mobile apps — alongside scout (headless browser automation), sequa (Postgres migrations + type-safe codegen), corral (a unified runtime for coding-agent CLIs) and selo (Brazilian CPF/CNPJ validation).

Above all I care about Clean Code: the best code is the code the next person can read without asking. Clear is better than clever.
